# m5_b1 — Эмбеддинги и семантический поиск

## Выбор embedding-модели

Для семантического поиска по базе багов были сравнены три модели на
mini-benchmark из 9 предметных пар.

| Модель | Accuracy | Средний запас | Первый запуск | Повторный запуск |
|---|---:|---:|---:|---:|
| text-embedding-3-small | 88,9% | 0,0819 | 15,385 сек. | 1,466 сек. |
| BAAI/bge-m3 | 88,9% | 0,0713 | 9,684 сек. | 0,038 сек. |
| intfloat/multilingual-e5-small | 88,9% | 0,0199 | 60,068 сек. | 16,239 сек. |

Все модели ошиблись на одной и той же сложной предметной паре №3.
Разметка пары проверена и признана корректной.

Для проекта выбрана `text-embedding-3-small`, поскольку при одинаковой
точности она показала наибольший средний запас между релевантным и
нерелевантным документом — 0,0819. Модель подходит для русскоязычных
описаний багов и не требует загрузки модели в оперативную память
локального компьютера.

База содержит 103 документа. При расчёте стоимости индексации учитывались
номер и дата бага, название, тема, влияние, статус, временное решение
и описание. При реализации RAG номер и дата будут дополнительно
сохраняться как метаданные документа.

Результат расчёта:

- всего документов: 103;
- всего токенов: 24 674;
- среднее количество токенов: 239,55;
- минимум: 83;
- максимум: 691;
- цена модели: $0.02 за 1 млн токенов;
- стоимость полной индексации: $0.00049348.

Повторные запуски используют дисковый кеш. Ключ кеша включает название
провайдера, модели, размерность и исходный текст, поэтому при смене
модели старые векторы не переиспользуются.
